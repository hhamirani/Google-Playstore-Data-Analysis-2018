# Google-Playstore-Data-Analysis-2018

Google Play Store Data Analysis

A Python data analysis project originally created in December 2018.

The project uses the Google Play Store app dataset to explore app ratings, reviews, installs, pricing, categories, and other attributes. It provides a simple command-line interface for interacting with the dataset and uses Pandas and Matplotlib for data analysis and visualization.

# Features
Load and clean Google Play Store data from a CSV file
Search for apps by name
Add new apps to the dataset through manual input
Export the modified dataset to a new CSV file
Analyze app ratings, prices, reviews, and installations
Compare paid and free apps
Visualize relationships between price, reviews, ratings, and installs
Analyze total installs by app category

# Technologies

Python

Pandas

Matplotlib
